# Task Manager

A Task Manager built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Move tasks between To Do, In Progress, and Done
- Delete tasks
- Set task descriptions and subtasks
- Filter tasks by date and completion status
- Save tasks using LocalStorage
- Focus timer
- Weekly focus report
- Light and dark themes

## Technologies

- HTML
- CSS
- JavaScript
- LocalStorage

## Getting Started

### Option 1: Live Server

1. Clone this repository:

   ```bash
   git clone https://github.com/mobina-sr/TaskManager.git
   ```

2. Open the project folder in VS Code.

3. Right-click `index.html` and select **Open with Live Server**.

4. The project will open in your browser.

### Option 2: npm start

1. Clone this repository:

   ```bash
   git clone https://github.com/mobina-sr/TaskManager.git
   ```

2. Open the project folder:

   ```bash
   cd TaskManager
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the local server:

   ```bash
   npm start
   ```

5. Open the local URL shown in the terminal in your browser.
